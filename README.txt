STORAGE FINDER (Fabric 1.21.11)

BUDOWANIE BEZ INTELLIJ (przez GitHub):
1. Załóż konto na github.com i utwórz nowe repozytorium (New repository).
2. Kliknij "uploading an existing file" i przeciągnij CAŁĄ zawartość folderu storagefinder
   (razem z folderem .github - jeśli jest ukryty, wgraj go osobno).
3. Wejdź w zakładkę Actions - build ruszy sam (ok. 3-5 min).
4. Kliknij zakończony build, na dole w "Artifacts" pobierz storagefinder-jar.
5. Rozpakuj, wrzuć .jar do .minecraft/mods razem z Fabric API.

BUDOWANIE Z TERMINALA (bez IntelliJ):
Zainstaluj JDK 21 i Gradle 9.2, w folderze projektu wpisz:  gradle build
Plik: build/libs/storagefinder-1.0.0.jar

Klawisz K w grze = menu moda.
